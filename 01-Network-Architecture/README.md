# Module 1 – Network Architecture & Topology

## Project
Design and Monitoring of Multi-Department Corporate Network

## Objective
To design the basic network architecture and topology
of a multi-department corporate network.

## Departments
- HR
- Finance
- IT
- Sales
- Management
- Servers

## Network Structure
Internet → Corporate Router → Core Switch → Department Switches → PCs

Server Switch → Web Server + DNS Server

## VLAN Plan

| Department | VLAN | Network |
|------------|------|---------|
| HR | 10 | 192.168.10.0/24 |
| Finance | 20 | 192.168.20.0/24 |
| IT | 30 | 192.168.30.0/24 |
| Sales | 40 | 192.168.40.0/24 |
| Management | 50 | 192.168.50.0/24 |
| Servers | 60 | 192.168.60.0/24 |

## Network Devices
- 1 Corporate Router
- 1 Core Switch
- 5 Department Switches
- 1 Server Switch
- 10 PCs
- 1 Web Server
- 1 DNS Server

## Software Used
- draw.io
- VS Code
- Java

## Member 1 Contribution
Designed the overall network architecture and topology,
including the router, core switch, department switches,
PCs and servers. This topology provides the base design
for the remaining project modules.
